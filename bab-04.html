MATERI UTAMA

Pokok bahasan Bab 04

Ringkasan konsep dan contoh penerapan untuk membantu menghubungkan materi dengan aktivitas sehari-hari.

01

Sistem komputer

Sistem komputer merupakan gabungan perangkat keras dan perangkat lunak yang bekerja bersama. Komputer menerima masukan, memprosesnya, menghasilkan keluaran, dan dapat menyimpan data.

CONTOH PENERAPANSaat mengetik, keyboard menjadi input; CPU memproses; layar menampilkan output; penyimpanan menyimpan dokumen.
02

Perangkat keras

Perangkat keras adalah bagian fisik komputer. Contohnya perangkat masukan seperti keyboard dan mouse, pemroses seperti CPU, perangkat keluaran seperti monitor dan printer, serta media penyimpanan.

CONTOH PENERAPANFlashdisk dan SSD digunakan untuk menyimpan data agar dapat dibuka kembali.
03

Perangkat lunak

Perangkat lunak adalah program yang memberi instruksi kepada komputer. Sistem operasi mengelola sumber daya perangkat, sedangkan aplikasi membantu pengguna melakukan tugas tertentu.

CONTOH PENERAPANSistem operasi mengatur perangkat; aplikasi pengolah kata membantu membuat dokumen.
04

Bilangan biner

Komputer menggunakan representasi digital yang dapat dinyatakan dengan dua simbol, yaitu 0 dan 1. Bilangan biner menggunakan nilai tempat berbasis pangkat dua.

CONTOH PENERAPAN101 dalam biner bernilai 5 dalam desimal: 1×4 + 0×2 + 1×1.
05

Siklus input–process–output

Sistem komputer menerima masukan, memprosesnya, menghasilkan keluaran, dan dapat menyimpan hasil ke media penyimpanan.

CONTOH PENERAPANKeyboard memasukkan teks, CPU memprosesnya, monitor menampilkan hasil, dan penyimpanan menyimpan dokumen.
06

Perangkat masukan dan keluaran

Perangkat masukan mengirim data ke komputer, misalnya keyboard, mouse, scanner, mikrofon, dan barcode reader. Perangkat keluaran menyajikan hasil, misalnya monitor, printer, dan speaker.

CONTOH PENERAPANScanner memasukkan gambar dari kertas, sedangkan printer menghasilkan salinan pada kertas.
07

CPU dan memori

CPU menjalankan operasi aritmetika, logika, kendali, serta input/output. RAM menyimpan data sementara saat proses berjalan, sedangkan ROM menyimpan instruksi dasar yang diperlukan saat perangkat mulai bekerja.

CONTOH PENERAPANAplikasi yang sedang dibuka menggunakan RAM untuk menyimpan data kerja sementara.
08

Perangkat lunak dan bilangan biner

Perangkat lunak sistem mengelola kerja komputer, sedangkan aplikasi membantu pengguna melakukan tugas. Data digital diproses dalam bentuk biner yang menggunakan digit 0 dan 1.

CONTOH PENERAPANSistem operasi mengatur perangkat, sementara aplikasi pengolah kata digunakan untuk membuat dokumen.

CONTOH MISI 02
