TUJUAN BAB 03

Mengenali antarmuka pengguna, mengelola folder dan file, menggunakan peramban serta mesin pencari, memahami surel, dan mengenal aplikasi perkantoran.

MATERI UTAMA

Pokok bahasan Bab 03

Ringkasan konsep dan contoh penerapan untuk membantu menghubungkan materi dengan aktivitas sehari-hari.

01

Antarmuka pengguna

Antarmuka pengguna adalah bagian yang membantu manusia berinteraksi dengan perangkat atau aplikasi. Bentuknya dapat berupa tombol fisik, menu grafis, ikon, layar sentuh, atau perintah suara.

CONTOH PENERAPANSaat mengetuk ikon kamera di ponsel, kamu menggunakan antarmuka grafis untuk menjalankan aplikasi.
02

Folder, file, dan ekstensi

File menyimpan informasi seperti dokumen, gambar, atau audio. Folder membantu mengelompokkan file agar mudah ditemukan. Ekstensi di akhir nama file memberi petunjuk jenis file.

CONTOH PENERAPANContoh: .jpg untuk gambar, .mp3 untuk audio, .pdf untuk dokumen, dan .docx untuk dokumen pengolah kata.
03

Peramban dan mesin pencari

Peramban (browser) adalah aplikasi untuk membuka halaman web. Mesin pencari membantu menemukan informasi di internet berdasarkan kata kunci yang dimasukkan.

CONTOH PENERAPANChrome atau Firefox adalah peramban, sedangkan Google atau Bing merupakan mesin pencari.
04

Surel dan aplikasi perkantoran

Surel digunakan untuk mengirim dan menerima pesan elektronik. Aplikasi perkantoran membantu membuat dokumen, mengolah angka, atau menyusun presentasi.

CONTOH PENERAPANSebelum mengirim surel, periksa alamat penerima, subjek, isi pesan, dan lampiran.
05

GUI, CLI, dan VUI

Antarmuka pengguna dapat berbentuk grafis (GUI), baris perintah (CLI), atau suara (VUI). GUI memakai ikon dan elemen visual, sedangkan CLI menerima perintah teks.

CONTOH PENERAPANMengetuk ikon kalkulator adalah interaksi GUI; mengetik perintah di terminal adalah interaksi CLI.
06

Struktur folder dan pengelolaan file

Folder dapat berisi file atau folder lain sehingga membentuk struktur bertingkat. File Manager digunakan untuk membuat, menyalin, memindahkan, mengganti nama, dan menghapus file.

CONTOH PENERAPANFolder utama Tugas dapat memiliki subfolder Matematika, Bahasa, dan Informatika.
07

WWW, URL, dan tautan

World Wide Web berisi halaman yang saling terhubung melalui hyperlink. URL merupakan alamat untuk menemukan halaman atau sumber tertentu di web.

CONTOH PENERAPANTautan pada sebuah halaman dapat membawa pembaca ke halaman lain yang berhubungan.
08

Aplikasi pengolah kata dan presentasi

Aplikasi perkantoran membantu membuat dan menyunting dokumen, mengolah data, serta menyusun presentasi. Pengolah kata memiliki fitur pemformatan, sedangkan aplikasi presentasi menyusun informasi menjadi slide.

CONTOH PENERAPANGunakan heading untuk membedakan judul dan subjudul dokumen, serta slide ringkas untuk mendukung penjelasan lisan.
